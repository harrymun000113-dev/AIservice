# AI 도구함

분야별 AI 서비스 67건을 한눈에 보고, **1분 만들 때 드는 비용**까지 비교하는 정적 웹사이트입니다.
HTML · CSS · JavaScript만 사용했고 빌드 과정 없이 Netlify에 그대로 올릴 수 있습니다.

> 데이터 기준일: 2026.10.07 (AI 서비스 조사 통합표). 요금과 기능은 자주 바뀌니 가입 전 공식 페이지에서 한 번 더 확인하세요.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 분야·요금 필터, 검색 | 10개 분야 칩, 무료/무료+유료/유료 필터, 이름·설명·용도 검색, 정렬 |
| 상황으로 찾기 | "논문 찾기", "회의 내용 정리", "돈 안 들이고 시작" 같은 버튼 12개 |
| 상세 패널 | 장점·단점·추천 용도·요금 플랜, 사이트 바로가기(새 탭), 다른 분야 평가 보기 |
| 비용 비교 | 영상·음성·음악·회의 기록 1분당 비용 막대 그래프, 화질 전환, 생성 횟수 슬라이더, $/₩ 전환 |
| 월 구독료 비교 | 글쓰기·디자인처럼 분량 기준이 없는 분야는 가장 저렴한 유료 플랜 월 요금으로 비교 |
| 내 AI 스택 | 서비스를 담으면 월·연 합계, 예산 초과 여부, 겹치는 구독, 분야 커버리지를 계산하고 링크로 공유 |
| 기타 | 반응형(모바일 지원), 다크/라이트 테마, 키보드 조작 가능 |

## 실행 방법

빌드가 필요 없습니다.

- **VS Code**: Live Server 확장 설치 → `index.html` 우클릭 → *Open with Live Server*
- **터미널**: 이 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000` 접속
- `index.html`을 더블클릭해도 열리지만, 로컬 서버로 여는 것을 권장합니다.

## 데이터 수정하기

서비스 정보는 엑셀(AI 서비스 조사 통합표)에서 관리하고 스크립트로 변환합니다.

```bash
pip install openpyxl
python tools/xlsx_to_services.py "엑셀파일경로.xlsx"
```

실행하면 `js/services.js`, `data/ai-services.json`, `data/ai-services.csv`가 다시 만들어집니다.
`js/services.js`는 자동 생성 파일이라 직접 고치지 말고 엑셀을 수정한 뒤 다시 변환하세요.

- 요금은 `무료 / 유료 / 무료+유료` 3종으로 통일됩니다. 세부 표기는 상세 패널에 그대로 나옵니다.
- 가장 저렴한 유료 월 가격(`minPaidUSD`)은 엑셀의 '월 가격 / 비고' 첫 줄에서 읽습니다. 원화·유로·연 결제 표기는 `tools/xlsx_to_services.py`의 `MIN_OVERRIDE`에서 보정합니다.
- 1분당 비용은 `js/costs.js`를 직접 수정합니다. 공식은 아래와 같습니다.

## 비용 계산 방식

```
1분 비용 = 플랜 월 요금(USD) × 1분당 소모 크레딧 ÷ 플랜 월 제공 크레딧
```

- 공개 자료의 크레딧 소모량(5~10초 기준)을 1분으로 환산한 **추정치**입니다.
- 서비스마다 모델·화질·음성 포함 여부가 달라 정확한 1:1 비교가 아니라 규모를 보는 용도입니다.
- 환율은 1달러 = 1,400원(`js/costs.js`의 `COST_FX`)으로 가정했습니다.
- Typecast 베이직·플러스·프로, Fish Audio Pro 이상, 무제한 플랜은 월 제공량을 확인하지 못해 계산에서 뺐습니다.
- 안 써본 서비스의 장단점은 리뷰·비교 글 요약이며, 직접 체험한 내용과 구분해서 보세요.

## Netlify 배포

1. 이 폴더를 GitHub 저장소로 올립니다.
2. Netlify에서 *Add new site → Import an existing project*로 저장소를 연결합니다.
3. Build command는 비워 두고, Publish directory는 `.`(루트)로 둡니다.
4. 배포 후 코드를 `push`하면 자동으로 반영됩니다.

공개하고 싶지 않다면 `tools/` 폴더를 빼고 올려도 사이트는 동작합니다.
